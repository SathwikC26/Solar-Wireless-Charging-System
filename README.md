# Solar Wireless Charging System

## Project Overview
This college project explores a solar-powered wireless charging system with an IoT-based current monitoring component. The provided Arduino firmware uses an ESP8266 microcontroller, an ACS712 current sensor, and Firebase Realtime Database to collect and transmit electrical monitoring data.

## Technologies Used
- Arduino IDE and Arduino C/C++
- ESP8266 Wi-Fi microcontroller
- ACS712 current sensor
- Firebase Realtime Database
- Internet of Things (IoT)

## My Involvement
The hardware and initial Arduino source code were provided by my college management team. This repository documents the supplied firmware and the technologies used in the project.
